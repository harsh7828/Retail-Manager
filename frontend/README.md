# ProfitPilot AI Frontend

React + Vite dashboard for the `ProfitPilot AI` retail decision engine.

## Features

- Sales and forecast trend chart (Recharts)
- Recommendation panel with confidence and explainability
- KPI cards for inventory and demand metrics
- Profit simulator for discount and timing strategy
- API integration with FastAPI backend

## Environment

Copy `.env.example` to `.env`:

```bash
VITE_API_BASE_URL=http://127.0.0.1:8000
```

## Run Locally

```bash
npm install
npm run dev
```

Open the local Vite URL shown in terminal (usually `http://localhost:5173`).
